<h2 align='center'>🖼️ About Me</h2>

Frontend-разработчик с 3+ годами коммерческой разработки веб-приложений на React, TypeScript и Next.js. Специализируюсь на создании масштабируемых SPA, проектировании frontend-архитектуры и разработке сложных пользовательских интерфейсов.

Имею опыт запуска проектов с нуля до production, интеграции с REST API, управления состоянием через Redux Toolkit, оптимизации производительности, написания unit-тестов на Jest и разработки переиспользуемых компонентов. Работал с адаптивной версткой, асинхронной обработкой данных, оптимизацией рендеринга и производительности React-приложений.

Работал в кросс-функциональных командах, участвовал в техническом планировании, code review, декомпозиции задач, развитии продукта. Принимал участие в проектировании новых модулей, выборе технических решений, рефакторинге существующего кода и внедрении единых стандартов разработки.

Уделяю особое внимание качеству кода, удобству сопровождения, производительности приложений и пользовательскому опыту. Следую современным практикам разработки, принципам SOLID, DRY и KISS, постоянно изучаю новые технологии и стремлюсь создавать надежные, масштабируемые и поддерживаемые frontend-решения.
